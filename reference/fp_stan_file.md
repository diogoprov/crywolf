# Path to the Stan program

Path to the Stan program

## Usage

``` r
fp_stan_file()
```

## Value

The path to the Stan file shipped with the package, for users who want
to read the model or modify a copy of it.

## Examples

``` r
fp_stan_file()
#> [1] "/home/runner/work/_temp/Library/crywolf/stan/fp_occu.stan"
```
